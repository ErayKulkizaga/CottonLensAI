# CottonLensAI work plan: one goal, one chain (15 Nov 2026)

The user approved this on 15 Nov 2026. All trials are logged in [CROP_NOWCAST_TRIALS.md](CROP_NOWCAST_TRIALS.md).

## The goal
Predict two things before each USDA Crop Production report:
- **(a)** USDA's next revision of US cotton production;
- **(b)** the cotton price move on that report day.

Everything else (satellite, FSA, weather, GPU models, ensembles) is an input to (a) or (b).

```
inputs (satellite, FSA, drought, condition, USDA's past errors)
   -> Link 2: predict USDA's next revision
   -> Link 1: revision -> report-day price move
   -> Link 3: subtract the market's expectation (analyst consensus), if an archive exists
```

## Rules
- **Seal.** It covers report events as well as production.
  - USDA figures and report-day returns for 2022–2025 stay unread until a preregistration is pushed and the user gives an explicit yes.
  - Any repo file containing those years is filtered to 2021 or earlier before anything is printed.
- **The one shot** is reserved for the chain's final claim, not for an intermediate result such as T25.
- **Gates.** Each link has a gate written before its results. A new success criterion is shown to the user before the test runs.
- **Reproducibility.** Results come from the pinned environment. `docs/CLAUDE_HANDOFF.md` is never committed.
- **Commits** go to `claude/hls-move3`. New code goes in `research/chain/`.

## Order
1. **Link 1: event study, 2012–2021.** Do report-day returns move more than other days, and does their sign follow USDA's revision? This is cheap and uses existing data.
   - The draft gate is in [LINK1_EVENT_STUDY_PREREG_20261115.md](LINK1_EVENT_STUDY_PREREG_20261115.md).
   - If price does not react, the chain has no price payoff. The user is told, and the work returns to (a) alone.
2. **Link 2: predict the revision.**
   - Reuse the rolling harness in `usda_correction.py`.
   - A model must beat both zero revision and the past-mean revision (the T25 analogue).
   - The GPU and Prithvi trials enter only here, against the same gate.
   - The Kaggle→Colab resumable pipeline is built only when the GPU trial starts: a manifest of units with hashes, a shared store, no recomputation, and checkpoints.
3. **Link 3: consensus, time-boxed.**
   - Try to retrieve the pre-report average trade estimate for two past reports from two independent public sources.
   - Continue only if one source covers most events. Otherwise record it as unavailable.
4. **Forward piece.** If Links 1 and 2 give a rule, lock and push a prediction for the 10 Dec 2026 report. This needs the user's push approval.

## Earlier work this builds on
- **Price level forecasting failed.** The Codex era ran 113 experiments: WASDE regional, Texas condition and weak signal. All daily T+1 price MAE tests stayed below the 5% target. Those runs never tested report-day behaviour.
- **Risk models.** Range, big-move and interval models were confirmed in a preregistration. They can supply event-day volatility baselines.
- **Production.** The satellite and FSA nowcast work (T01–T27) supplies the inputs to Link 2.
